# YU Tasks

Стартовый каркас платформы задач Yessenov University. Сейчас доступен адаптивный интерфейс на русском и английском; списки задач и аналитика показывают пустое состояние до появления реальных данных.

## Запуск

Нужен Go 1.23 или новее. Из корня репозитория:

```sh
go run .
```

Сервер слушает `http://localhost:8080`, создаёт SQLite базу в `data/yu-tasks.db` и применяет миграции. Настройки перечислены в `.env.example`; файл `.env` автоматически не загружается, передавайте переменные окружения средствами вашей оболочки.

## Структура

- `main.go` — запуск HTTP-сервера, базы и встроенной статики.
- `internal/` — конфигурация и платформенный код.
- `migrations/` — миграции Goose, только вперёд.
- `web/` — интерфейс, встраиваемый в Go-бинарник.
- `docs/` — ADR, открытые вопросы, дизайн, безопасность и приватность.

## Проверки

```sh
go test ./...
go vet ./...
```

CI также запускает `staticcheck`, тесты с `-race` и `govulncheck`.

## Известные открытые вопросы

Смотрите [docs/OPEN_QUESTIONS.md](docs/OPEN_QUESTIONS.md). OIDC-провайдер не выбран; `dev-login` предназначен только для локальной разработки и запрещён при `YU_ENV=production`. Юридические и инфраструктурные требования не предполагаются без заключения и согласования.

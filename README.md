# YU Tasks

Платформа задач Yessenov University. Реализованы локальный вход для разработки, публикация и взятие задач, настройка запрещённых категорий деканатом и каталог товаров с данными из SQLite. Интерфейс на русском и английском; пока реальные товары не внесены, каталог остаётся пустым.

## Запуск

Нужен Go 1.23 или новее. Из корня репозитория:

```sh
go run .
```

Сервер слушает `http://localhost:8080`, создаёт SQLite базу в `data/yu-tasks.db` и применяет миграции. Настройки перечислены в `.env.example`; файл `.env` автоматически не загружается, передавайте переменные окружения средствами вашей оболочки.

Чтобы включить локальный выбор роли, запустите `YU_DEV_LOGIN=1 go run .`. Dev-вход разрешён только на loopback-адресе; в `production` сервер откажется запускаться с этим флагом. Сессии локальной разработки хранятся в памяти и пропадают после перезапуска.

## Структура

- `main.go` — запуск сервера, HTTP API задач и применение middleware.
- `internal/` — конфигурация и платформенный код.
- `migrations/` — миграции Goose, только вперёд.
- `web/` — интерфейс, встраиваемый в Go-бинарник.
- `docs/` — ADR, открытые вопросы, дизайн, безопасность и приватность.

## Проверки

```sh
go test ./...
go vet ./...
```

CI также запускает `staticcheck`, тесты с `-race` и `govulncheck`.

## Известные открытые вопросы

Смотрите [docs/OPEN_QUESTIONS.md](docs/OPEN_QUESTIONS.md). OIDC-провайдер не выбран; `dev-login` предназначен только для локальной разработки и запрещён при `YU_ENV=production`. Юридические и инфраструктурные требования не предполагаются без заключения и согласования.

Публикация задач открывает их сразу после серверной проверки правил. Магазин пока поддерживает каталог и управление товарами; покупка и оформление заказа появятся после гроссбуха EC. Приёмка результата, начисление EC и вход через университетский OIDC будут отдельными следующими срезами.

# ADR 0001: Go-сервер и встроенный веб-интерфейс

- **Контекст:** пилоту нужен простой способ запускать сервер и интерфейс одной командой без отдельного процесса для фронтенда.
- **Решение:** использовать Go, один бинарник и стандартный `net/http` с роутером `chi`; статические файлы из `web/` встраивать через `embed`. Локальный запуск — `go run .` из корня репозитория.
- **Компромиссы:** один процесс упрощает запуск и поставку, но связывает выпуск интерфейса с выпуском сервера и требует дисциплины в границах пакетов; `chi` добавляет зависимость, зато сохраняет привычную модель `net/http`.
- **Статус:** принято.

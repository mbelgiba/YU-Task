# ADR 0006: Нативный веб-интерфейс без сборщика

- **Контекст:** интерфейс должен запускаться вместе с Go-сервером и не зависеть от отдельной сборочной среды на этапе пилота.
- **Решение:** использовать нативные ES-модули, CSS-переменные и локальные файлы переводов без Node.js и сборщика; `web/` встраивается в бинарник. На первом этапе поддержать русский и английский интерфейсы. Казахскую локализацию добавить после проверки носителем. Наличие Node.js отмечено как вероятное, но это не меняет решение для пилота.
- **Компромиссы:** отсутствие сборщика упрощает установку и уменьшает число зависимостей, но лишает статической типизации и части оптимизаций больших фронтенд-проектов; русский и английский можно запустить раньше, но расширение языков потребует отдельной проверки переводов и полноты строк.
- **Статус:** принято.

# ADR 0002: SQLite и миграции базы данных

- **Контекст:** для локальной разработки и ограниченного пилота нужна база без отдельного сервера и без CGO; при этом модель данных не должна намеренно привязываться к SQLite.
- **Решение:** использовать `modernc.org/sqlite` без CGO и `goose` для миграций только вперёд. SQL писать в переносимом подмножестве PostgreSQL/SQLite и изолировать особенности драйвера в `internal/platform/db/`.
- **Компромиссы:** SQLite снижает операционные требования, но ограничивает параллельную запись и не является подтверждённым выбором для нагрузки вуза; совместимый SQL уменьшает, но не устраняет стоимость перехода на PostgreSQL — особенности типов, блокировок и миграций всё равно потребуют адаптации и проверки.
- **Статус:** принято.

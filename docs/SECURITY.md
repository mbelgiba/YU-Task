# Безопасность: начальный чек-лист OWASP ASVS

Статус описывает только каркас. Он не означает завершённый аудит или готовность к продуктивной эксплуатации.

| Область | Статус | Примечание |
|---|---|---|
| Архитектура и конфигурация | Частично | Запрет dev-login при `YU_ENV=production`; проверка конфигурации покрыта тестом. |
| Аутентификация | Частично | Локальный выбор роли разрешён только на loopback и запрещён в production. OIDC-провайдер ещё не выбран; учётные записи `local.invalid` создаются только для разработки. |
| Сессии и CSRF | Частично | Dev-сессия — `HttpOnly`, `SameSite=Strict`, ограничена по времени и хранится в памяти; изменяющие запросы требуют CSRF-токен и совпадающий Origin. Для production нужны OIDC, Secure cookie и проверка срока/отзыва сессии. |
| Авторизация и tenant isolation | Частично | API публикации, взятия задачи, редактирования правил и каталога проверяет роль на сервере; SQL выборок включает tenant. Покупки ещё не включены. |
| Валидация и SQL | Частично | Входы задач/правил ограничены по размеру и длине, значения проверяются, запросы параметризованы; негативные тесты есть для ролей и запрещённых категорий. |
| HTTP-заголовки | Частично | Добавлены CSP, `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options`; CSP нужно проверить вместе с будущими потоками. |
| Ограничение частоты | Не реализовано | Нужны лимиты входа и покупок после появления этих операций. |
| Загрузка файлов | Не реализована | Не принимать файлы до определения типов, лимитов и отдельного хранилища. |
| Аудит чувствительных действий | Частично | Публикация, взятие задачи, изменение правил и добавление товара журналируются транзакционно; нужен аудит остальных операций. |
| Зависимости | Частично | CI запускает `govulncheck`; регулярность и результаты ещё не подтверждены. |
| Персональные данные | Ожидает юриста | См. `PRIVACY.md` и маркер `[ВОПРОС: заключение юриста]`. |

## Перед пилотом

Сверить выбранную версию ASVS с командой безопасности, закрыть все применимые пункты, проверить негативные сценарии чувствительных операций и пройти независимое ревью. Текущий документ не является заключением о соответствии.

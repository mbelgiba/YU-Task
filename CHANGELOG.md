# Changelog

## 2026-10-06

- Добавлены ADR 0001–0007 и документация открытых вопросов, дизайна, безопасности и приватности.
- Создан Go-сервер с chi, встроенной статикой, SQLite и Goose миграциями.
- Добавлен адаптивный интерфейс на русском и английском со светлой/тёмной темами и пустыми состояниями.
- Добавлены CI-проверки Go и начальный конфигурационный тест для запрета dev-login в production.
- Добавлены локальные role-сессии, серверные проверки доступа к публикации/взятию задач и настраиваемый деканатом список запрещённых категорий.
- Добавлены транзакционные записи аудита для задач и правил, экран публикации, список задач, «Моя работа» и экран правил.
- Взятие задачи выполняется условным атомарным обновлением; повторная параллельная попытка получает конфликт.
- Каталог магазина загружается из SQLite; сотрудники могут добавлять товары с ценой в EC и остатком. Покупки пока не реализованы.
- Контентная область растянута на всю ширину окна браузера; каталог адаптивно перестраивается под ширину экрана.
- Для локального dev-просмотра добавлены три явно помеченных макета товаров с оригинальными SVG-иллюстрациями; при первом входе каждому локальному аккаунту один раз выдаётся 10 000 EC.
- Добавлен план развития платформы в `docs/ROADMAP.md`; покупки и автоматическая награда за приёмку задач остаются следующими отдельными срезами.
